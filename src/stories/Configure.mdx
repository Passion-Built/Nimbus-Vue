# Nimbus UI

A neumorphic Vue component library built on soft shadows and light.

Nimbus UI is a coded UI kit for Vue 3 that embraces neumorphism — using subtle inset and raised shadows to create depth and tactile, approachable interfaces. Components support both light and dark themes out of the box.

## Features

- **Neumorphic design** — Soft, shadow-based styling that gives components a physical, extruded feel
- **Light and dark mode** — Full theme support with CSS custom properties
- **Vue 3** — Built with the Composition API and `<script setup>`
- **Accessible** — Form components include proper labeling, ARIA attributes, and keyboard support
