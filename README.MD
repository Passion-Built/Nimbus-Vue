# Nimbus UI Kit - Vue.js

Nimbus is a minimalist, neumorphism-inspired UI kit designed for developers and designers who want clean, soft, and tactile interfaces. This kit focuses on **styling and design foundations** — typography, color tokens, spacing, shadows, and core components — without adding complex functionality, making it perfect for portfolios, prototypes, and projects.

## Features
- **Foundations:** Typography scale, color tokens, spacing, border-radius, soft shadows, and icon usage guidelines.
- **Components:** Buttons, inputs, textareas, selects, images, avatars, links, dialogs, and core primitives (Box, Flex, Grid, Text, Heading).
- **Accessibility:** Focus states, semantic HTML, color contrast, and minimal touch target standards.
- **Lightweight & flexible:** Designed to be easily customized and extended, perfect for both personal projects and professional prototypes.

## Getting Started
1. Include the CSS / token files in your project.
2. Apply foundation tokens to your components.
3. Use styled primitives and components to quickly build neumorphic interfaces.
4. Swap in your preferred fonts and color schemes as needed.

Nimbus is open-source and free to use under the MIT license. Perfect for rapid styling, portfolio projects, and prototyping with a modern, soft UI aesthetic.
